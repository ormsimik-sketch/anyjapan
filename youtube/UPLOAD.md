## Название

## Описание
Где-то во Вселенной идут дожди из стекла, а на ночной стороне другой планеты с неба падает расплавленное железо. Лёд там может не таять даже при +400 °C, а в центре нашей галактики висит облако, которое пахнет малиновым ромом. В этом выпуске — 10 самых странных мест, которые нашли астрономы. Место №1 удивит вас больше всего.

## Настройки при загрузке
- Категория: «Образование» (или «Наука и техника»), язык видео: русский.
- «Видео для детей»: **Нет**.
- **«Изменённый или синтетический контент»: Да.** Голос синтезирован, графика сгенерирована. YouTube требует ставить эту отметку, сама по себе она монетизации не мешает.
- Субтитры: загрузите `subtitles.srt` (Субтитры → Добавить → Загрузить файл → «С таймкодами»).
- Конечная заставка: последние 20 секунд ролика (13:26–13:46), сюда можно поставить кнопку «Подписаться» и ссылку на следующее видео.
- Обложка: `thumbnail.jpg`.

# Как пересобрать или сделать следующий выпуск
```bash
sudo apt-get install -y rhvoice rhvoice-russian sox ffmpeg
pip install numpy pillow
B=build; mkdir -p $B
python3 make_audio.py $B                 # озвучка, таймлайн, субтитры
python3 make_music.py $B && sox $B/music_dry.wav $B/music.wav reverb 85 50 100 100 10 2 lowpass 6000 gain -n -1
seq 0 11 | xargs -P 4 -I{} python3 render.py $B {}   # видеоряд по сценам
python3 make_thumb.py $B                 # обложка
bash assemble.sh $B                      # итоговый final.mp4
```
Новый выпуск = новый `script.py` (текст разбит на фразы, у каждого раздела указан тип сцены `visual`).
